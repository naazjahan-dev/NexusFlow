# NexusFlow — Visual IoT Telemetry & Rule Engine

NexusFlow is a modern, responsive IoT monitoring and management dashboard designed to visualize device telemetry, manage connected devices, configure automation rules, and monitor system alerts through a premium web interface.

## 🚀 Project Overview

NexusFlow aims to simplify IoT device monitoring and management through an interactive dashboard with real-time-style telemetry visualization, device management tools, analytics, and rule-based automation.

## 💻 Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to Project Folder

```bash
cd NexusFlow
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📌 Current Implementation Notes

- Telemetry data is simulated when real IoT hardware or backend services are unavailable.
- Browser LocalStorage is used for frontend demonstration and data persistence.
- Authentication is intended for demonstration and is not production-secure.
- Real hardware connectivity and production backend integration require additional services.
